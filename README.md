Esse programinha é um jogo simples de adivinhar um número. 
Quando você roda ele, o computador escolhe um número aleatório
entre 0 e 100, mas sem te contar qual é, obviamente. 
A sua missão é ir chutando até acertar.

Você digita um número, aperta Enter, e o programa te diz se você errou 
por cima ou por baixo — tipo: “o número é maior” ou “o número é menor”. 
Aí você vai ajustando seus palpites até chegar no número certo.

No final, quando você acerta, ele fala quantas tentativas você precisou. 
É basicamente um jogo de “quente ou frio”, só que mais direto. Bem simples de usar: a
brir, digitar número, receber dica, repetir até acertar. Pronto.
